### 📌 Proyek Unggulan

#### 🏢 AbsenKita (Sistem Presensi Karyawan PWA)
Aplikasi presensi mandiri karyawan untuk mencegah titip absen dan manipulasi lokasi GPS.
- **Tantangan yang Diselesaikan:** Deteksi wajah dijalankan langsung di perangkat karyawan menggunakan WebAssembly, sehingga server tidak terbebani streaming video.
- **Fitur Utama:** Verifikasi wajah hidup (liveness), batas radius GPS kantor, penanganan shift malam lintas hari, serta dashboard rekapitulasi untuk admin dan pimpinan.
- **Stack:** Laravel 12, PostgreSQL Supabase, MediaPipe, Tailwind CSS.
